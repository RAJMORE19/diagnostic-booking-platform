### Important interview question

**Why should an EC2 instance use an IAM Role instead of AWS Access Keys?**

Practical answer:

> I don't store AWS access keys inside an EC2 server. I attach an IAM Role to the EC2 instance, and AWS provides temporary credentials automatically. This is more secure, avoids hardcoded secrets, and follows the least-privilege principle.

# 8. ALB Health Check

Understand why this matters.

Example:

```text
ALB
 │
 ├── EC2-1 → Healthy
 │
 └── EC2-2 → Unhealthy
```

ALB automatically stops sending traffic to EC2-2.

For FastAPI:

