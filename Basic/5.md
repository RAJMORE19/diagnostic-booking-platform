* DNS

* TTL
* Domain → ALB

Instead of:

```text

```


Flow:

```text

Route 53
 ↓
ALB
 ↓
EC2
```

### Important interview question

**Why use Route 53 instead of directly giving users the ALB DNS name?**

Because Route 53 gives you controlled DNS management and lets you map a stable domain name to AWS resources such as an ALB.

# 4. AWS Secrets Manager

Your Day 4 application had:

```env
DATABASE_HOST=...
DATABASE_USER=...
DATABASE_PASSWORD=...
```

Do **not** put sensitive credentials directly into:

```text
GitHub
Dockerfile
docker-compose.yml
EC2 scripts
application source code
```

Instead:

```text
AWS Secrets Manager
        │
        ↓
      EC2
        │
        ↓
    FastAPI
        │
        ↓
       RDS
```

Store:

```text
DB_HOST
DB_NAME
DB_USER
DB_PASSWORD
```

as a secret.

---

# 5. IAM + Secrets Manager

This is where Day 4 IAM becomes important.

EC2 gets an IAM Role:

```text
EC2 IAM Role
      │
      ↓
secretsmanager:GetSecretValue
      │
      ↓
Secrets Manager
```

The application retrieves the secret using the AWS SDK.

### Interview question

**Why is Secrets Manager better than putting passwords in environment variables?**

Good answer:

> Environment variables can still be useful for non-sensitive configuration, but for production secrets I prefer AWS Secrets Manager because access is controlled through IAM, secrets are centrally managed, and rotation can be implemented without storing credentials in source code or images.

# 10. Auto Scaling Scenario

Suppose traffic increases:

```text
Normal traffic
      ↓
    EC2-1
    EC2-2
```

Traffic increases:

```text
High traffic
      ↓
CloudWatch
      ↓
ASG Scaling Policy
      ↓
EC2-3
      ↓
ALB
```

Traffic decreases:

```text
Low traffic
      ↓
ASG
      ↓
Terminate unnecessary instance
```

---

# 11. EC2 Self-Healing

Suppose:

```text
EC2-1
  ↓
CRASH
```

ASG detects the unhealthy instance:

```text
ASG
 ↓
Remove EC2-1
 ↓
Launch new EC2
 ↓
Register with Target Group
 ↓
ALB sends traffic
```

This is **self-healing infrastructure**.
